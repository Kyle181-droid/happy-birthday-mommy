# Untuk Syahrani Akhyar — A Little Universe

Website ulang tahun interaktif dengan rose-opening animation, 34 petals, gratitude-first letter, wishes, birthday cake and optional Web Audio melody.

## Paling cepat: buat link publik (Netlify Drop)
1. Buka https://app.netlify.com/drop di browser.
2. Ekstrak `syahrani-birthday-website.zip` di komputermu.
3. Seret **folder `syahrani-birthday`** yang berisi `index.html`, `styles.css`, dan `script.js` ke zona unggah Netlify Drop.
4. Tunggu sampai Netlify memberi alamat website `*.netlify.app`; salin link-nya untuk dikirim.

Link sandbox/local atau file:/// **bukan link publik**. Untuk link yang dapat dibuka dari HP orang lain, unggah ke hosting.

## Jalankan lokal
- Klik `untuk-syahrani-akhyar.html` untuk file tunggal standalone.
- Atau jalankan index.html di folder ini lewat Live Server / `python -m http.server 8000`.

## Ubah konten
- Copywriting ada di `index.html`.
- Styling/animasi ada di `styles.css`.
- Interaksi dan animasi kelopak di `script.js`.

Tidak memakai bundler, framework, tracking, atau dependensi JS. Font Google dipakai dengan fallback Georgia/sans-serif saat offline. Mendukung reduced-motion dan keyboard.
